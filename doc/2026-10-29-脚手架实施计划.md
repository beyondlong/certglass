# CertGlass 基础脚手架实施计划

> 后续 agent：按任务逐项实施与验证；可按需使用 `executing-plans`。不自动启动子代理、不提交代码。

**目标：** 交付可编译的 macOS 应用骨架、可替换的模块接口、必要的行为测试和独立可读的交接文档。

**架构：** 沿用已确认的技术方案。Swift Package 管理 Core（模型和协议）、Infrastructure（待实现适配器）、Features（状态协调和 SwiftUI）；原生 Xcode 应用与 SwiftPM 可执行入口复用同一组应用源码。真实容器解析、证书解析、系统信任与导出由后续 agent 实现。

**技术栈：** Swift 6、macOS 13+、SwiftUI、Foundation、CryptoKit；脚手架不新增第三方依赖。

## 验证策略

- `swift test`：领域契约和状态协调测试，依赖测试替身，不访问钥匙串或网络。
- `swift build -c release --product CertGlass`：同时编译 SwiftUI 外壳和模块。
- `scripts/build-app.sh`：验证应用包、Info.plist 和可执行文件装配。
- 完整 Xcode 可用时：`xcodebuild -project CertGlass.xcodeproj -scheme CertGlass -configuration Debug -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build`。
- 证书算法矩阵、真实链评估及网络行为验收留给相应功能实现任务，不在脚手架阶段宣称完成。
